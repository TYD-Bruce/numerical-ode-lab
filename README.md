# Numerical ODE Lab

Numerical ODE Lab is a beginner-friendly web app for visualizing numerical methods for ordinary differential equations.

## Features

- Choose a numerical method
- Input an ODE model
- Set initial time, final time, step size, and initial data
- Compute numerical approximations
- Display the final value
- Display a table of values
- Plot the numerical solution

## Supported Methods

- Forward Euler
- Backward Euler
- Taylor method of order 2
- Runge-Kutta 4
- Adams-Bashforth 2-step
- Adams-Moulton 2-step
- Leapfrog method
- BDF2
