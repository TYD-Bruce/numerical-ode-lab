not among the 197 stable IDs. They are reported, not silently added.

## Compact dependency summary

```text
ordinary_differential_equation + initial_condition
  → initial_value_problem
  → numerical_approximation + exact_solution + step_size
  → time_grid

numerical_approximation + exact_solution + time_grid
  → nodal_error
  → global_error
  → final_time_error + maximum_global_error
  → observed_order + order_of_convergence
  → asymptotic_region

test_equation [required-ID gap] + step_size
  → scaled_stability_parameter [required-ID gap]
  → stability_function
  → stability_region + absolute_stability
  → a_stability
  → stiffness

matrix + vector
  → linear_system
  → residual

vector + scalar → vector_norm
matrix + scalar → matrix_norm
matrix_norm + invertible_matrix → condition_number
```

Dependencies are a directed graph, not a single curriculum. `stiffness`,
for example, also depends on problem behavior and practical step-size
restrictions; A-stability alone is not its definition.
