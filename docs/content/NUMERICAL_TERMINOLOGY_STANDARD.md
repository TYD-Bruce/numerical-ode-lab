## How to read this standard

Each identifier is stable. A row records approved terminology and a separate
content-readiness status; it is not a production Glossary entry. The nine
maintainer decisions resolved all 18 formerly blocked terminology rows. The
remaining `CORE_PROJECT_DRAFT`, `MODULE_DRAFT`, `FUTURE_CANDIDATE`,
`DEFERRED`, and `OUT_OF_SCOPE` labels describe content readiness, not whether
the language standard is approved. Source locators are representative and use
abstract keys only.

The standard keeps distinct mathematical senses as separate IDs, even when ordinary English uses the same word. Full candidate coverage, including deferred and out-of-scope items, is retained so future module work does not silently re-invent terminology.
