# Numerical Terminology Standard

Status: Private-source-reviewed draft; maintainer approval pending.

## How to read this draft

Each identifier is stable within this review package. A row records a draft term, not a production Glossary entry. `DECISION_REQUIRED` rows must not be migrated into product copy until the decision log is reviewed. Source locators are representative and use abstract keys only.

The standard keeps distinct mathematical senses as separate IDs, even when ordinary English uses the same word. Full candidate coverage, including deferred and out-of-scope items, is retained so future module work does not silently re-invent terminology.
